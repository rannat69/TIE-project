# Instructor How‑To Manual (Frontline Boost / Project Tracking)

This manual walks you through the **Administrator UI journey**: what you’ll see on-screen and what to click to manage users, courses and projects.

## What this app does (Admin view)

- **User management**: you add or delete users, then give them a role (student, instructor or admin).
- **Course management**: you create courses and assign them instructors.
- **Project management**: you create projects and assign them students.

## Access and accounts

### Sign in

1. Open the app.
2. Go to **Sign in**.
3. Sign in using the method your program uses (for example, email + password or a sign-in link).

After signing in, you’ll land on the **Administrator** dashboard.

### If you land on the wrong dashboard

If you sign in successfully but see a **Student** or **Instructor** screen , contact your program admin so they can enable admin access for your account.

## Admin dashboard overview

You’ll see three main tabs:

- **Users**: List of users of the app.
- **Courses**: Lisst of available courses.
- **Projects and team**: List of projects.

## Manage your users

### Add a new user

1. Open the **Users** tab.
2. Press **Add user**.
3. Enter a name, an email address and a role. Then, press **Create user**

You’ll see the user appear in the list.

You can now delete it or change its role.

### Delete a user

1. Find the user in the list
2. Press the trashcan icon next to it

### Change a user's role

1. Find the user in the list
2. Select a role in the corresponding dropbox.

### Add students to a course

1. Open the **My courses** tab.
2. Find the course card you want.
3. In **Course students**, use **Add student to course…** to add a student.

## Manage your courses

### Add a new course

1. Open the **Courses** tab.

2. Enter a code, a name, and a term. Then, press **Add course**

You’ll see the course appear in the list.

### Add an instructor to a course

1. Find the course in the list
2. Select an instructor in the corresponding dropbox.
3. The instructor will now appear in the course box.

### Remove an instructor to a course

1. Find the course in the list
2. Press the x next to the instructor in the course box.

## Manage your projects

### Add a new project

1. Open the **Projects** tab.

2. Enter a project name, select a course, and enter a desription. Then, press **Add project**

You’ll see the project appear in the list.

### Add an student to a project

1. Find the project in the list
2. Select a student in the corresponding dropbox.
3. The student will now appear in the project box.

### Remove an student to a project

1. Find the project in the list
2. Press the x next to the student in the project box.

## Common “what you’re seeing” fixes (admins)

### “I can sign in, but I see Student dashboard”

- Your account likely isn’t enabled for instructor access yet.
- Message your program admin and ask to be set up as an admin.
